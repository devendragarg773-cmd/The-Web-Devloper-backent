# THE WEB DEVELOPER BACKEND
Build: npm install
Start: npm start
Render env: OWNER_PASSWORD=@ND0710, JWT_SECRET=YOUR_LONG_RANDOM_SECRET, FRONTEND_ORIGIN=*
For persistent SQLite on Render, mount a Persistent Disk at /var/data and set DATA_DIR=/var/data.
API: /api/health, /api/auth/login, /api/projects, /api/projects/:id, /api/settings, /api/settings/policy, /api/settings/banner
